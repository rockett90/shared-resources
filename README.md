## How this repo is organised

Top-level folders group things by type (`latex/`, `code/`, `hardware/`). Inside
each, every item is a **self-contained folder** with:

- a `README.md` explaining what it is and how to use it,
- the actual files, and
- a `preview.png` / screenshot if it's something visual.

So adding a new thing is always the same move: make a folder, drop your files
in, write a short README, and add a line to the list above.
