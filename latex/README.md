# LaTeX

LaTeX templates. Each subfolder is a standalone template — copy the folder,
compile (`latexmk -pdf main`), and replace the placeholder content with your own.

| Template | What it is |
|----------|------------|
| [technical-doc-template](technical-doc-template) | General-purpose technical document / report / dissertation template. Modular preamble, front matter, worked electronics examples, bibliography and nomenclature support. |
| [cv-template](cv-template) | Two-page CV, matching visual identity. ATS-friendly text layer; everything you change lives in one `CONFIG` block. |

Both compile with **pdfLaTeX** and work on Overleaf. Each folder has its own
`README.md` with full instructions.
