\section{Example Appendix Content}
\label{app:exampleAppendix}

This appendix provides a simple example of how appendices can be added to
documents created with this template. In a real project, this section might
contain supporting material such as:

\begin{itemize}
  \item Detailed calculations or derivations that would clutter the main text.
  \item Additional plots, figures, or tables used for internal analysis.
  \item Supporting code snippets, test procedures, or measurement logs.
\end{itemize}
