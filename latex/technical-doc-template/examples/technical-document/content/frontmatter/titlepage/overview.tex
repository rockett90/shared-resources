This note covers the design of the anti-aliasing filter that sits between the
sensor amplifier and the 12-bit ADC input of the microcontroller. It sets out
the requirements, the choice of a second-order Sallen-Key low-pass filter, the
component values and the predicted performance across component tolerance,
along with the firmware sampling arrangement and the tests planned for the
first boards.
