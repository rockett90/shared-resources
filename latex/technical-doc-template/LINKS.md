# Useful Links

Reference URLs for working with this template. The CircuiTikZ and tikz-timing
entries relate to the electronics example content; ignore them if you are not
using circuit or timing diagrams.

## Editors and helpers

- **LaTeX pretty-printer** — tidies up markup
  https://c.albert-thompson.com/latex-pretty/

- **Equation editor** — visual LaTeX equation builder
  https://latex.codecogs.com/eqneditor/editor.php

- **CircuiTikZ editor** — drag-and-drop circuit diagram editor that
  exports to CircuiTikZ
  https://circuit2tikz.tf.fau.de/designer/
